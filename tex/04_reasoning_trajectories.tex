\section{Reasoning trajectories and objective-relative state}
\label{sec:reasoning}

\subsection{Literature review}

\subsubsection{Written reasoning and action traces}

Chain-of-thought prompting elicits written intermediate steps before an answer and improves several reasoning tasks at sufficient model scale \parencite{wei2022chain}. ReAct extends the trace with actions and observations, so intermediate text supports both deliberation and interaction with an environment \parencite{yao2023react}. These methods establish the practical value of extra computation in the sequence. They do not show that each written step matches a discrete internal update or that the text faithfully records the cause of the answer.

Work on efficient entity tracking makes the state problem more exact. Standard attention needs growing depth for a chain of state changes in the formal setting studied by \textcite{fagnou2024chain}, while their modified attention composes the chain more directly. This result concerns an architectural route for updating state, not the existence of a task-general unit in a pretrained model's free-form explanation.

\subsubsection{Hidden trajectories and mechanistic state}

Mechanistic analyses ask which internal components move or write task information. On fictional ontology tasks, \textcite{dutta2024step} report a split between earlier relation transfer and later answer-writing paths. Across abstract rule and analogy tasks, \textcite{yang2025symbolic} identify early symbol abstraction, intermediate induction, and late retrieval components. These studies support structured, task-linked computation, but their units come from the chosen task and intervention target.

Trajectory work shifts the unit of analysis from a component to a position or step. \Textcite{qian2025peaks} identify ``thinking tokens'' with high estimated mutual information, \textcite{yu2025stateaware} study state-aware changes across reasoning stages, and \textcite{sun2026trajectories} report step-specific geometry and correctness signals. The methods differ in target, estimator, and granularity. Their findings motivate a direct test of whether boundaries selected for answer formation, symbolic updates, correctness, and geometric compression agree when the token budget stays fixed.

\subsubsection{Latent reasoning and reusable interfaces}

Continuous latent reasoning removes the requirement that every intermediate state decode to text. Coconut feeds hidden states back into the model as continuous thoughts and trains their repeated use \parencite{hao2025coconut}. A later preprint uses causal perturbations and adversarial tests to argue that apparent latent reasoning can instead rely on weakly meaningful placeholders in some settings \parencite{zhang2025latenttokens}. This disagreement makes output quality alone insufficient evidence for a reusable state interface.

The gap is therefore not a lack of candidate structure. Prior work finds useful tokens, stages, circuits, and latent states, but each selects a notion of state through its task and measure. This chapter asks two stricter questions: whether one token decomposition remains useful across several objectives, and whether a decoded or produced state remains sufficient after the source history is removed and the state is used again. We began with the simpler idea that a long verbal derivation might hide a short series of stable updates. Because projections and probes can reveal correlations that the model never uses, the experiments move from geometry to held-out prediction, intervention, explicit handoff, and recursive closure.

\subsection{Layer schedules: a qualified pilot}

To turn the literature's qualitative claims about reasoning stages into a falsifiable first test, we started with the simplest question: does the depth at which an apparent stage occurs remain stable when the same computation is expressed differently? Here a \emph{layer schedule} means the relative transformer depth at which markers associated with successive stages of the solution become strongest. The pilot used matched versions of the same linear problem written in symbolic, ordinary natural-language, deliberately ornate, and length-padded symbolic form, so changes in wording and changes in token length could be separated.

Only problem quartets answered correctly in all four forms entered the main analysis. The fitted fraction of model depth assigned to the middle stage was 0.593, 0.667, 0.667, and 0.704, respectively; natural minus symbolic was $+0.074$ with a paired 95\% interval $[0.037,0.111]$. Phrasing changes the observed layer schedule, but padding changes it as well, so token position and length remain confounds.

We also tried simple causal checks rather than relying only on the curves: a targeted suppression intervention at layer 14 and an activation patch from a symbolic prompt into its natural-language counterpart. Both were directional on one clean pair but did not yield stable statistical results. Finite-difference gain estimates local sensitivity; it is not a global Lipschitz constant. A separate synthetic depth-generalization pilot (ChaCAL) reached exact accuracy 1.00, 0.64, and 0.58 at depths 1--3 before falling near chance. Its held-out depths used unseen positions, some tasks allowed parallel reductions, and reinforcement learning omitted the hard depths. The owning repository therefore marks the depth claim as invalid. Its role in this report is to explain the stricter gates used in later causal work.

The pilot changed our standard for a mechanistic claim. A layer curve alone was no longer enough. Later tests had to survive prompt-length controls, choose intervention layers without looking at the test set, and change the downstream variable named by the hypothesis.

\subsection{Trajectory pipeline and first hypotheses}

The layer pilot suggested that coarse depth profiles were too confounded to identify a native unit of reasoning. We therefore moved to token-resolved arithmetic reasoning trajectories, where textual boundaries, symbolic state changes, latent geometry, causal transfer, and correctness could be compared on the same generated solutions.

The main trajectory corpus records generated text, correctness, token-to-sentence alignment, symbolic updates from a restricted arithmetic parser, and hidden states by token and layer. Projections are fitted on training data so held-out labels cannot select a representation. Question-disjoint splits keep every solution on one side of the split. Exact parsers or symbolic simulators replace model judges where the task permits.

By a \emph{solution object} we meant a compact intermediate representation corresponding to one meaningful reasoning update: ideally it would appear at a recognizable boundary, have a localized latent signature, and remain usable when transferred into an equivalent computation. The first five hypotheses tested different consequences of that idea---alignment to text boundaries, localization in geometry, causal portability across process-isomorphic traces, grouping by operation, and prediction of correctness.

None of the tests found one event with all five properties. Text boundaries did not define a stable latent partition. Symbolic changes spread across windows and changed direction instead of appearing as one sharp jump. Prespecified attention- and MLP-output process-isomer patches did not rescue target behavior. Raw geometry gave weak operation groups, although supervised projections decoded operations. In the tested corpus, sentence summaries predicted correctness better than the proposed latent segments. Objective-specific structure remained plausible; a single naturally exposed event did not.

We initially treated the five hypotheses as routes to the same object. They were testing different properties: alignment to text, localization in geometry, causal portability, semantic identity, and predictive value. Averaging their disagreement would have hidden that distinction. We designed the token-lattice experiment to hold the candidate boundaries and budget fixed while changing only the objective.

\subsection{No universal partition of the token lattice}
\label{subsec:objective-relative-partition}

Every generated-token transition was eligible as a boundary. Each trace received the same boundary budget: its number of verified symbolic updates, capped at 64, with a primary minimum separation of four tokens and sensitivity checks at one and eight. Utilities were normalized so random selection has expectation zero and the target oracle has score one. An \emph{oracle} for one objective is allowed to see that objective's true scores when selecting boundaries; it therefore provides the objective-specific upper reference rather than a deployable segmentation rule.

The four objectives were: increase in alignment with a gold-solution state; completion of a verified symbolic update; absolute change in a train-only correctness probe; and change between local mean states in train-only PCA space. Baselines included sentences, raw magnitude, cosine and curvature peaks, random boundaries, each objective oracle, and supervised detectors that did not receive the objective score as an input.

The held-out evaluation covered 310,044 SmolLM3-3B tokens and 61,691 Qwen3-14B tokens. Oracle overlap within four tokens was low: F1 ranged from 0.098 to 0.210 for SmolLM and 0.130 to 0.294 for Qwen. The best worst-objective utility was only 0.020 and 0.080, and remained stable under the one/four/eight-token sensitivity sweep. Sentence boundaries scored near zero on answer and symbolic-object utility. Raw cosine peaks retained some answer utility, about 0.30 in both models, so the result is non-dominance rather than absence of shared signals.

Supervised detectors recovered their own boundaries with held-out ROC--AUC scores of 0.999/0.984/0.849/0.868 for SmolLM and 0.998/0.992/0.859/0.825 for Qwen (answer, object, correctness, and compression, respectively). Strong diagonal decoding rules out the explanation that the trace contains no structure. Weak cross-objective utility shows that the learned structures differ.

The supervised diagonals rule out an absence of structure. Instead, the visible structure changes with what the partition must preserve. The same token can mark the formation of an answer direction, carry little value for a symbolic update, and matter again for local compression. This result shifted the project from searching for one partition to testing utility-relative ones.

\subsection{Judged semantic spans}

The four utilities were deliberately operational, but that leaves a natural objection: perhaps they miss the semantic steps that a human reader would call ``reasoning.'' To test that alternative, a larger model labeled 415 overlapping windows from concise correct SmolLM traces with nine edit types: orient, bind variable, add relation, derive value, verify, correct error, plan, extract answer, and mixed. Exact text matching aligned 406 windows. After removing spans that touched internal window edges, the audit retained 1,761 intervals over 58 traces; the median span was 29 tokens.

A question-disjoint latent detector reached AUC 0.982 for all semantic boundaries and 0.969 for boundaries away from sentence ends. A matched text character model reached 0.956 and 0.775. The latent advantage off sentence boundaries was 0.193 with a question-bootstrap interval $[0.115,0.301]$. Eight non-mixed semantic types were decodable from held-out span activations with macro one-vs-rest AUC 0.891 and macro-F1 0.487, but lexical TF--IDF reached AUC 0.892 and their combination 0.901. Unsupervised PCA-cosine reached only 0.623. Thus the ontology is present, but labels and lexical cues select it.

The boundaries supplied by these semantic labels form a semantic oracle. It still scored $-0.012/0.043/0.036/0.324$ on the four earlier utilities, and the learned semantic detector recovered semantic utility but not answer or symbolic-object utility. The result uses only 12 held-out GSM-Symbolic traces selected for concise correct reasoning; its labels are silver rather than human gold. The ontology therefore provides another useful decomposition, but its weak transfer to the earlier objectives strengthens rather than weakens the utility-relative account.

\subsection{Exact control: snapshot information is not memory}

Objective-relative segmentation still leaves a separate causal question. A state may be easy to decode at one instant yet fail as memory when the system must continue updating it. To isolate that distinction from language-model generation noise, we introduced a finite controller in which the latent state, memory update, and planning objective are exactly known. The controller receives observations generated by a finite hidden state and must act over a future horizon using a prescribed memory representation; because the transition model and planner are explicit, its performance can be evaluated without model-judge noise.

Three finite latent families, six held-out split types, eight memory budgets, and four continuation horizons form 90 task cells and 1,710 complete representation rows. Exact source weights and exact finite-horizon planning ensure that each controller plans through its own memory update. Forty independent tests and a raw-row audit verify split, capacity, planning, and gate contracts.

At evaluation start, full public history and a 12-bit text suffix have identical support, state mutual information (2.512 bits), and \emph{path leakage} (1.781 bits) in all 90 cells. Path leakage measures information retained about the particular history leading to the current state, beyond merely identifying that state. The two representations nevertheless match in regret in zero cells: pooled text regret is 7.19 times full-history regret. At horizon 32, regret is 2.20 for full history and 30.91 for text. The source history has depth two, so both representations encode the same initial observations; the suffix then forgets future observations during continuation. Initial decodability is therefore insufficient for long-horizon use.

A 12-bit \emph{field state}---an explicit code that stores selected components of the underlying finite state rather than a suffix of observation text---removes 79.3\% of no-memory regret, compared with 93.7\% for full history and 54.8\% for text. It matches full history in every non-continual split but fails when held goals require fields not selected by the training objective. Capacity must be paired with an allocation rule that retains transfer-relevant state. This is an exact finite construction, not learned-model evidence.

Because the environment, posterior, planner, and rollout are all exact, the comparison isolates the missing property cleanly: a representation must summarize the current history, and its update rule must continue to retain the needed information as new observations arrive.

\subsection{Native language-model state and explicit handoff}
\label{subsec:native-state-handoff}

The exact control establishes what a reusable memory must do, but not whether a pretrained language model naturally exposes such a state. We therefore returned to an LLM with a deliberately factorized synthetic task. A short addition program determines one of eight possible three-bit endpoint states; a separate pointer table maps each endpoint state to the final answer. This lets us test four abilities separately: reading a supplied state, applying one update, synthesizing the endpoint of a history, and composing that endpoint with the final lookup.

On these balanced three-bit addition programs, frozen Qwen2.5-32B reads a supplied state and applies a local update perfectly. At horizon two it synthesizes the history endpoint with 76.98\% accuracy but composes that endpoint with the pointer table at only 13.44\%, near eight-state chance. An \emph{explicit handoff} removes the original history after the model predicts the endpoint and passes that predicted state to a fresh model call; this raises accuracy to 76.98\%. A \emph{gold handoff}, which passes the correct endpoint instead, and stepwise decimal execution both reach 100\%. State information exists, but the one-pass prompt does not route it into the final operation.

Hidden probes also retain path detail, and the tested late-layer state subspace does not beat a random subspace control. This prevents a stronger claim that the frozen model exposes one transferable native code. The explicit handoff is a causal repair created by the evaluation protocol.

We had searched for a hidden location to patch, but the model could perform each local operation without routing the endpoint through the final lookup. We stopped searching for an assumed native interface and supplied one explicitly, then tested what properties it needed.

\subsection{Rate, shared meaning, and closure}
\label{subsec:state-closure}

Once an explicit handoff repaired the routing failure, the next question was what makes such an interface genuinely reusable rather than a one-off prompt trick. We separated three requirements: enough rate to distinguish the necessary states, shared meaning between the model that produces a code and the model call that consumes it, and \emph{closure}---after applying one rule to a valid code, the model must emit another valid code with the correct state meaning so that the result can be fed back recursively.

Qwen2.5-7B LoRA adapters were trained to emit one \emph{opaque state token}: a symbol drawn from a small codebook whose surface form carries no task semantics. For an eight-state addition task, code alphabets of size 4, 8, and 16 correspond to declared capacities of 2, 3, and 4 bits. Producer, consumer, and test contexts are disjoint. The two-bit code necessarily merges the eight true states into four classes; its transitions are internally closed on those classes, and its answer accuracy is exactly 50\%, the resulting information ceiling. The canonical three-bit code assigns one stable symbol to each state and scores 74.27\% at horizon two and 42.19\% at horizon sixteen. A redundant four-bit code provides extra symbols and scores 97.71\% and 59.48\%.

Capacity alone is not enough if the symbols do not have a stable meaning. In a \emph{context-bound dictionary}, the token used for a semantic state depends on the surrounding context rather than providing one shared name that producer and consumer can agree on; these conditions remain near chance. Matched closure training instead supervises code-plus-one-rule to next-code, while endpoint training supervises full-history to endpoint code. Both use 20,000 forwards, 5.12 million fixed-padding tokens, and 20,000 one-token targets. At horizons eight and sixteen, redundant closure reaches 97.81\% and 97.08\%, beating endpoint training by 43.85 and 44.58 points. Across five shifted history families it averages 93.25\% at horizon sixteen versus 48.50\% for the endpoint control. These one-seed addition results show the value of closure, but may reflect fitting a small transition table.

The addition study therefore separated questions that earlier tests had joined. The two-bit code imposed an exact information ceiling. Context-bound dictionaries tested whether producer and consumer shared a meaning, while transition training tested closure under self-produced codes. After these controls behaved as predicted, the main remaining concern was whether the positive result merely fit a tiny addition table.

\subsection{Canonical proof state and failure controls}

Because addition has only eight states and a small transition table, success there could reflect memorization rather than a reusable state contract. We therefore moved to a qualitatively different finite proof system. Its state is a four-bit \emph{fact ledger} recording which of four facts are currently true; deterministic Horn-style implication rules update that ledger one deduction at a time. Evaluation performs one model call per rule, discards prior rules, and supplies only the resulting state code to the next call or final consumer.

Three Qwen seeds compare four code contracts over the 16 possible ledgers: a lossy three-bit code $s\bmod 8$ that must merge states; a canonical code with one stable token per state; a five-bit padded code $2s$ that has extra unused capacity but still one name per state; and a five-bit path-aliased code $2s+b_{\rm path}$ that deliberately gives the same semantic state two possible names depending on how it was reached. Every condition uses equal data and compute.

Canonical and padded codes recover all 16 states in all three seeds and keep exact state through horizon 256. Mean final accuracy is 97.22\% for the canonical interface versus 72.22\% one-pass, a paired gain of 25 points with context-bootstrap interval $[12.50,38.89]$. The three-bit code has one bit of residual state uncertainty and 0\% exact state. Extra unused code symbols do not hurt the padded code. Path aliases do: at three active deductions the aliased code has only 30--40\% exact state, versus 100\% for the matched-size padded code; at horizon 256 its local closure is 63.85--71.50\%.

Two preset validity checks do not pass. On an easier full-support evaluation bank, the padded and aliased codes do not separate; and even when the final consumer is given the correct state code directly, accuracy does not exceed 95\% for every code surface and seed. The result therefore supports enough rate, one stable name per state, and exact closure in this finite proof system, but it does not show that every sufficient surface is equally readable. Nor does a horizon of 256 imply 256 active deductions, or that the interface saves inference compute: a horizon-256 case uses 257 model calls.

A codebook can therefore have ample rate while assigning several names to the same semantic state. Those names retain irrelevant path information. The matched five-bit padded code shows that extra capacity alone is harmless. The aliased code uses the extra symbol to preserve history and loses recursive closure. This control ties the explicit interface to the objective-relative result: information can be available yet make a state less stable when it is irrelevant to the chosen future.

The proof task still uses a simple, structured update family. To stress whether closure survives heterogeneous transitions rather than one regular transition system, we next moved to mixed register programs with add, XOR, swap, and conditional updates. Three Qwen seeds apply these operations to their own supplied state with 88.55--90.69\% local semantic accuracy, yet complete horizon-32 accuracy is 7.92\%, versus 5.83\% one-pass and 6.25\% chance. Mistral gives the same failure pattern. A fifth code bit raises two complete seeds only to 12.81\% and 12.19\%. Modest local error compounds until the state loses almost all useful information.

The register failure limits the scope of the interface result. The producer learns each operation well enough to score strongly in a one-step table, but about 31 self-fed calls amplify its remaining semantic errors. A redundant bit does not repair an inaccurate transition kernel. The next measure should model how semantic confusions propagate under self-conditioned use instead of relying on gold-input one-step accuracy.

\FloatBarrier
\subsection{Takeaways}

The evidence rejects three shortcuts. A useful label need not coincide with a sharp geometric event. A decodable snapshot need not be useful memory. Enough nominal state symbols do not ensure a reliable recursive interface. Useful decompositions exist, but they depend on the utility. In controlled tasks, an explicit state channel can become sufficient and closed when its rate, naming, and self-conditioned transition accuracy each pass their own test.

Each failure narrowed the next test. Weak layer and boundary evidence prompted explicit objective comparisons. Their disagreement made us separate state content from state use. Failed native composition prompted an explicit handoff, whose gains then required rate and closure controls. Success on addition was followed by proof and register stress tests. The proof task shows that a small canonical state can compose under controlled conditions. The register task sets the present limit of that result.
