\begin{abstract}

This thesis studies how much information a language model must acquire or retain for a learned behavior to survive, across fine-tuning updates and intermediate reasoning states. For fine-tuning, we define an operational rate as the exact serialized size of a compressed LoRA or QLoRA adapter at a fixed level of retained held-out behavior. In these experiments, ordinary weight reconstruction error fails to predict behavioral preservation, and neither source description length nor the magnitude of the fine-tuning gain predicts the required rate. The ordering of the same corpora reverses across the frozen base models tested, indicating that adapter rate depends on the receiver as well as the data. Model-relative correction spectra provide the strongest predictor in the current campaign, although this remains a hypothesis rather than an established scaling law. On reasoning traces, different objectives select different partitions, and a state can be readily decodable without being reusable in downstream computation. Controlled explicit interfaces separate capacity from naming and update effects: enough bits are necessary, stable state names matter, and small one-step errors compound under repeated use. Together, these results suggest that useful information is not intrinsic to a dataset, adapter, or trace, but relative to a receiver, a task, and, under recursive use, an update rule.

\end{abstract}
