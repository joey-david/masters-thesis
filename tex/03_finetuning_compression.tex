\section{Fine-tuning under an information budget}
\label{sec:fineqcomp}

\subsection{Literature review}

\subsubsection{Low-dimensional adaptation}

Parameter-efficient fine-tuning shares a frozen model and changes a small learned object. Intrinsic-dimension results show that successful language-model adaptation can lie in a much smaller subspace than the full parameter space \parencite{aghajanyan2021intrinsic}. LoRA gives that constraint a practical form by learning a low-rank update to selected weight matrices \parencite{hu2022lora}. AdaLoRA then allocates rank by an importance score rather than fixing the same rank throughout the model \parencite{zhang2023adalora}. Work on LoRA factor asymmetry further shows that the input and output factors can contribute unequally despite having the same rank and similar storage cost \parencite{zhu2024asymmetry}.

This line studies where adaptation capacity should sit and how optimization should use it. Rank, however, is not a communication rate. Two rank-$r$ adapters can require different code lengths once precision, scales, sparsity, selectors, and metadata enter the message. The asymmetry result also warns that a codec based only on tensor size or reconstruction error can spend bits on the wrong part of the update.

\subsubsection{Quantization and quantization-aware adaptation}

Whole-model quantization provides several ways to allocate error. GPTQ uses approximate second-order information during sequential weight quantization \parencite{frantar2023gptq}. ZeroQuant uses hardware-aware groups and layer-wise distillation \parencite{yao2022zeroquant}; SmoothQuant moves activation difficulty into weights before applying integer quantization \parencite{xiao2023smoothquant}; and AWQ preserves channels selected from activation statistics \parencite{lin2024awq}. These methods show that equal nominal width does not imply equal functional cost across weights or layers.

Quantized fine-tuning changes a related but distinct object. QLoRA trains higher-precision adapters over a four-bit frozen backbone \parencite{dettmers2023qlora}. LoftQ chooses an initialization that reduces joint quantization and low-rank approximation error \parencite{li2024loftq}, while QA-LoRA aligns quantization groups with the adapter so that the learned change can merge into a low-bit model \parencite{xu2024qalora}. Their main targets are training memory, initialization error, or low-bit deployment. They do not directly measure the shortest complete file that reproduces the behavior of one fixed trained adapter.

\subsubsection{Description length, bounds, and the open measurement question}

Rate--distortion theory formalizes the least message rate compatible with a chosen distortion \parencite{berger1971rate,cover2006elements}. Minimum description length treats short joint descriptions as a model-selection principle \parencite{grunwald2019mdl}. Compression-based and PAC-Bayes work uses compressed networks or posteriors to derive generalization bounds \parencite{arora2018compression,zhou2019pacbayes,lotfi2022pacbayes}. Those theories motivate complete code accounting, but their aims differ from the empirical question here.

Two similar questions therefore imply different experiments. ``How many parameters can be trained?'' concerns capacity. ``How many bits must another machine receive to reproduce the learned behavior?'' concerns communication. Given a fixed backbone, adapter layout, trained checkpoint, and decoder, this chapter measures the shortest serialized adapter that retains a stated fraction of learned behavior. It counts decoder-visible metadata and tests the adapter only after decoding from disk. The resulting threshold is an empirical rate--distortion point, not a generalization bound.

\subsection{May pilots: sharpening the variable}

The initial Qwen2.5-0.5B QLoRA sweep used Alpaca and Dolly variants at ranks 0, 2, 4, 8, and 16. Most held-out-loss gain appeared between rank 0 and rank 2, with smaller gains thereafter. A Qwen2.5-1.5B repeat showed the same broad knee. Useful adaptation occupied a small low-rank subspace in these runs. They still did not identify an information rate because every rank stored floating-point factors and retraining mixed capacity with optimization.

We first thought that the knee itself might be the desired limit: perhaps the smallest effective rank measured how much the task needed to write. The repeat at a larger scale made this plausible until we inspected what rank left unspecified. Rank-two and rank-sixteen adapters are not messages at a defined rate unless their values, scales, and tensor layouts are encoded. Independent training also gives each rank a different optimization path. The rank curve was a capacity sweep, not the rate--distortion curve of one learned update.

The data controls also showed why row count was weak. Exact duplicates lowered ordinary compressed text size but changed epoch structure; template regularization changed both compressibility and format. A small ARC-Challenge sample was flat and noisy compared with held-out SFT loss, so it could not serve as the main distortion measure. Finally, $A$-only training stayed near baseline while $B$-only recovered much of full-LoRA performance in the tested setup. This functional asymmetry warned against allocating bits from tensor size alone.

Each failure exposed a confound. Duplicating data changed ordinary compressed text size and the number of times each unique example was revisited. Template regularization changed the base model's prediction task. ARC supplied too few binary outcomes to resolve small codec differences. We designed the next experiment to separate information from training exposure, compression from retraining, and dense prediction loss from noisy task accuracy.

\subsection{Fixed-checkpoint exact-rate protocol}

The later protocol trains one raw rank-16 adapter, freezes it, and derives a codec ladder without retraining. The base model, tensor order, codec, and evaluation program are shared side information. Each candidate writes a real file that includes selectors, scales, headers, packed payload, and compression overhead. A fresh path decodes that file and loads it into the base model before scoring.

The main quantizer uses symmetric zero-free mid-rise levels with a least-squares scale per row. At one bit this is $\operatorname{sign}(w)\operatorname{mean}|w|$. Fixed controls include uniform one- to eight-bit codes and zero-containing mid-tread codes. Sub-bit points drop paired LoRA rank directions, so an $A$ direction and its corresponding $B$ direction survive together. This distinction matters: sub-bit selection and one-bit quantization are different distortion mechanisms, although every data arm follows the same ladder.

The natural-task campaign uses Mistral-7B on an NF4 backbone, rank-16 all-linear LoRA, MetaMathQA training, 1,319 GSM8K test questions, and held-out NLL on 256 MetaMathQA rows. Seeds 11, 22, and 33 give independent training runs. Exact-match accuracy anchors behavior, while about 48,700 held-out tokens give a lower-variance estimate of prediction gain.

The protocol also defines a successful measurement. The raw adapter must clear an absolute learning gate, the codec ladder must cross the target, and the file must decode without access to the raw tensors. Only then is $\Rstar(.90)$ defined. In the first pass, every arm appeared to need 1.02 bits per value because the ladder stopped too early. These rules identify that outcome as censored rather than as a flat scientific result.

\subsection{Adaptive allocation: a negative result}

The adaptive codec allowed each row to be dropped or encoded at 1, 2, 3, 4, or 8 bits. A Lagrangian allocator minimized reconstruction error plus a code-length penalty. The hypothesis was that spending bits on rows with the best error reduction would dominate uniform coding at a matched file rate.

The adaptive codec did not dominate uniform coding. Row dropping could remove a required member of a LoRA pair, while a small global weight error could occur at a behaviorally sensitive location. In the decisive comparison, an adaptive point with lower adapter RMSE lost far more task behavior than a fixed-rate point with slightly higher RMSE. Thus $\|A-\widehat A\|$ does not order behavioral distortion. Later layer-allocation tests use held-out behavior as the selection target for this reason.

We expected the adaptive method to work because it priced each row by reconstruction improvement per bit. Its failure changed the research direction. A better global norm would not solve the problem if location and downstream use determined the cost of an error. We added uniform controls, paired sub-bit selection, and later the layer-band interventions to test those factors.

The fitted line in \Cref{fig:distinct-rate} hides part of the evidence. The arms begin to separate near a quarter bit per value and retain their ordering over much of the ladder; $\Rstar$ records one horizontal crossing of that change. The dense sub-bit extension was needed because the original one-to-two-bit sweep placed every crossing below its first measured point.

An eight-thousand-row follow-up separated content diversity from row count. With six seeds and roughly 400, 1,200, 3,600, and 5,620 distinct source problems, $\Rstar$ rose from 0.682 to 0.742 bits per value; the 400 and 3,600 seed ranges did not overlap. This supports content, rather than row count alone, as a cause. Yet pooled math runs also show that much of the change follows the behavioral gain achieved by the raw adapter.

The results initially suggested a simple account: more distinct content required a larger adapter message. Each arm, however, had also learned a different amount. Retaining 90\% of a larger prediction change sets a harder absolute target. We therefore designed the next controls to separate source information, achieved behavior, and task type.

\subsection{Known-information control}

A synthetic mapping task supplies an exact source-information count. Each prompt asks for one of 16 one-token labels. Conditions reuse prototype label tables so the number of independent four-bit draws is known. A conditional prequential code trains only on earlier blocks. Its preregistered uniform mixture prevents a confidently wrong model from assigning unbounded code length; a later switch-code fix also lets it fall back to the shared base model for a whole block.

The corrected code orders the 4, 64, 128, 256, and 512-bit conditions and lies within 1.1--3.5 times the known count. This validates it as a coarse data-information measure. Adapter $\Rstar$, however, is 0.842, 0.796, 0.663, and 1.013 from 64 through 512 source bits, with roughly $\pm0.3$ bits of seed spread. It does not track source information. The highest-information conditions saturate the finite prompt domain, while the adapter can encode a reusable rule rather than the sampled table. This negative result rules out the claim that dataset entropy alone sets adapter rate.

\begin{figure}[p]
\centering
\includegraphics[width=.98\linewidth]{fineqcomp/plots/known_information_validation.png}
\caption[Known source information versus adapter rate.]{Known-information control. The conditional code recovers the correct order of source information after the switch-code repair (left), but adapter $\Rstar(.90)$ does not follow the known bits (right). We built this experiment so that the proposed information measure could be checked against a known answer. The code passed that check, so a broken entropy proxy cannot explain the null $\Rstar$ relation by itself. The adapter can exploit structure shared across mappings. The bits sampled to create a dataset and the bits needed to implement a rule that fits it are different quantities.

\subsection{Searching for model-relative dataset information}

The first math panel suggested that the size of the learned change might set the budget: across 48 rank-16 runs, held-out bits saved explained $56\%$ of the variation in $\Rstar$. That fit covered only 0.16 bits saved per token. The completed response-transform grid breaks it. Five deterministic rewrites of the same answers nearly double the learned change, from 0.555 bits per token for plain narrow responses to 1.062 for symbolic responses, while $\Rstar$ moves from 0.684 to 0.763. Across all ten transform arms, the slope is 0.12 with $R^2=0.37$, against 1.90 in the original math fit. A 16-fold optimizer-budget sweep on identical content also moves prediction gain by only 0.04 bits per token while $\Rstar$ falls. The amount learned does not set the rate.

Changing the frozen receiver gives a sharper test. Five corpora were trained on both Mistral-7B and Qwen2.5-7B with the same rank, row count, epochs, and codec ladder. Only dialogue remains in the same position when the corpora are ordered from cheapest to most expensive. Instruction tuning moves from the cheapest Mistral arm to the second-most expensive Qwen arm; summarization and math move in the other direction.

The strongest counterexample comes from a task on which fine-tuning changes behavior most. On XBRL tag extraction, Mistral exact match rises from 0.004 to 0.833 and held-out prediction gain reaches 1.747 bits per token. Its mean $\Rstar$ is 0.371 bits per value, the lowest arm in the campaign. Across 38 pooled task--model arms, prediction gain and $\Rstar$ correlate $-0.37$. This rejects a positive cost law; the negative correlation is descriptive and does not establish an inverse law.

The XBRL result does not isolate abstract information. The groups are companies, and held-out examples cover all companies, so group count changes support coverage and training content together. Answer entropy remains nearly flat, which rules out a simple label-entropy account. Exact-match codec thresholds are too sparse and often hit the lowest scored rate, so the comparison uses the fully bracketed held-out-likelihood curves.

The failed source codes suggested a different object: information in the supervised correction relative to what the frozen model already predicts. We screened ten measures from one frozen-model pass over 256 training rows in each of 78 model--dataset--seed cells. They cover target code length, surprise concentration, representation rank, output-residual rank, and random sketches of the target gradients. For a scored token, the output-head gradient factors as
\[
g_{it}=h_{it}\otimes\left(p_{it}-e_{y_{it}}\right),
\]
where $h_{it}$ is the receiver's hidden state, $p_{it}$ its next-token distribution, and $e_{y_{it}}$ the target indicator. Fixed random projections reduce both factors before their outer product. The resulting empirical second moment $F=n^{-1}G^\top G$ describes how many correction directions the dataset requests and how large they are. The main scalar is
\[
I_{\mathrm{corr}}(D;M)=\log\det(I+F)=\sum_j\log(1+\lambda_j(F)).
\]
It is conditional on both dataset $D$ and frozen model $M$: changing either changes the residuals, hidden states, and gradient spectrum.

The reduction first averages the three seeds, then merges four exact data reuses between the high-gain and diversity panels. This leaves 22 distinct model--dataset arms in seven task families. Table~\ref{tab:relative-info-screen} reports the main screens. The permutation test shuffles $\Rstar$ within each model and uses the largest result across all ten candidates, which adjusts for choosing the best measure on this panel. The task-held-out fit leaves one whole family out and uses a model intercept plus one logged measure.

The correction spectrum also recovers the controlled split. Log-volume is nearly flat as SQL groups increase, with slopes $-0.0008$ and $+0.0031$ per doubling on Mistral and Qwen, but rises on XBRL with slopes $+0.0364$ and $+0.0353$. Effective rank retains a positive residual relation after model and task intercepts are removed ($r=0.566$). Its median seed coefficient of variation is 0.045; log-volume's is 0.018. Neither is a renamed learning-gain measure: log-volume has Spearman correlation $-0.275$ with held-out gain across the distinct arms.

This is the first proxy to clear the internal screen, but the panel remains a discovery set. The sketch covers the output-head gradient factor rather than the full LoRA Fisher, the same arms selected and assessed the ten candidates, and the receivers are only two 7B models. The current claim is therefore that a correction-gradient spectrum is a credible model-relative measure of learned-dataset information and predicts the measured thresholds in this panel. A locked prospective model--task panel must test the fixed definition before it becomes a scaling law.

Quadrupling rank from 16 to 64 raises whole-file $\Rstar$ by about threefold, from 28.6 to 82.7 Mbit in the 400-problem arm and from 41.4 to 129.3 Mbit in the 32,000-row arm. This is closer to container scaling than to a fixed task message. At matched 0.5- and 1.0-bit budgets, uniform allocation also beats starving the early, middle, or late third of layers; starving late layers costs most. Weight-update RMS stays nearly flat across depth while representation shift grows toward the last layer. No one band is dispensable in this test.

After the row allocator failed, we tested whether broad network location could guide bit allocation even though global RMSE could not. Uniform coding again won. The representation-shift curve still explains part of the sensitivity: small changes accumulate with depth, so the last layers show a larger functional displacement even though training moves adapter weights by similar RMS in each band.

\subsection{Takeaways}

Exact serialization asks how short a usable learned update can be, rather than how large an adapter was trained. The strongest current claim is conditional: the behavior-preserving bit budget tracks the spectral volume of corrections requested by the learned dataset relative to its frozen receiver. It does not track information intrinsic to the dataset, base loss, or the amount learned alone. Content diversity can shift the threshold at fixed rows, but the XBRL/SQL split shows that this effect depends on task structure.

Weight RMSE, source entropy, behavioral gain, divergence from the base model, rank, task type, and layer location each expose part of the system; none gives a task-independent law. The correction spectrum is the first tested measure that predicts across task families and follows the SQL/XBRL contrast, but it still needs a prospective test. In the five-corpus Mistral panel, about one bit per adapter value retains essentially all held-out gain, which is the broad practical result in that substrate. Below that rate, the ordering depends strongly on corpus, base model, and the model-relative corrections requested by the data.
